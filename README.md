# Mouse Movement Simulator

A personal passion project made to see if I could accurately simulate human-like mouse movements and avoid detection in a video game. 
Lacks features to easily switch between settings, but I didn't bother implementing them as it was intended as an experiment that only I would interact with. Randomized Bézier curves were used for the mouse trajectory, creating a smooth natural appearance with corrections being made to account for the precision required as the game window is rather small.
